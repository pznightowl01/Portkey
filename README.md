# PORTKEY

PORTKEY is a food ordering platform developed using Flask, SQLite, and machine learning based chatbot integration. The application enables users to browse restaurants, view menus, manage carts, place orders, and receive assistance through an intelligent chatbot.

## Project Features

* User authentication and authorization
* Restaurant and menu management
* Shopping cart functionality
* Order placement workflow
* Machine learning powered chatbot
* Responsive web interface
* Database-driven architecture

## Technology Stack

**Frontend**

* HTML
* CSS
* JavaScript

**Backend**

* Flask (Python)

**Database**

* SQLite

**ORM**

* SQLAlchemy

**Additional Integrations**

* Flask-Mail
* Razorpay Payment Gateway

## Purpose

This project was developed as part of the Software Engineering Laboratory coursework to demonstrate full-stack web application development, database management, payment gateway integration, and software engineering principles.
